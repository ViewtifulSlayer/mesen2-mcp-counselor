01 · What this is

A dossier, not a hint line.

There are no spoiler gates and no "are you sure you want to know" prompts. The pack describes the game the way a technician needs it: systems, addresses, tables, maps, and the evidence behind each claim. Read what the task needs.

Grounded claims

Every assertion is tagged [V] verified in the emulator, [D] derived from the ROM or data tables, or [U] unverified. You can see which is which.

Regional reality

Japanese sources are treated as first-class evidence, because regional releases hide differences that the English version quietly papers over.

Honest coverage

Coverage is declared per domain and the gaps are listed. A pack says "route beyond this town is an outline" instead of implying it is finished.

02 · The packs

Two certified, more welcome.

A pack is aimed at one game and one job: give an agent enough context to play, test, reverse-engineer, patch, or localize it without re-deriving the basics. Certification needs a recorded field test and a rubric score, not just prose.

03 · Anatomy

What is inside a pack.

The same six pieces in every pack, so an agent knows where to look before it knows the game.

SKILL.md

The entry point: what the pack covers, which files answer which question, and the minimal reading order for a task.

Seven references

Overview, world, systems, data, harness, edge cases, and regional variants. Each page names the question it answers.

Data with provenance

CSV tables for characters, enemies, items, spells, shops, maps, and encounters, each hashed in provenance.json.

Lua kit

Helpers and ready-made recipes so a probe is a tool call, not a fresh scripting project.

Field test

A recorded run against a named server version, with savestates and screenshots kept as evidence.

Source manifests

A public manifest credits titles, authors, and licenses. A local-only manifest holds paths and hashes for material that cannot ship, and stays gitignored.

04 · Install

Three steps, no build.

The library is additive. It does not touch the emulator or the MCP server, so you can drop it into an existing Mesen2 MCP checkout.

Get the server

Download the zip for your platform from the releases page and extract it somewhere permanent. It needs the .NET 8 runtime; Linux and macOS also need SDL2.

# Windows example
C:\Tools\mesen2-mcp\MesenMcpHost.dll

Install a pack as a skill

From the repository root, the installer copies public content only and prints the Lua library path for the next step.

python library/tools/install_pack.py --pack gb/final-fantasy-legend --target .agents/skills

Or take a pack bundle from the release and extract it straight into .agents/skills/<skill-name>/.

Point the client at the Lua kit

Add the printed --mcp-lib-dir value to the server arguments, then restart the client so it reloads the skill list.

{
  "mcpServers": {
    "mesen2-mcp": {
      "command": "dotnet",
      "args": [
        "C:/Tools/mesen2-mcp/MesenMcpHost.dll",
        "--mcp-lib-dir=C:/Tools/mesen2-mcp/.agents/skills/ffl-gameplay/lua/lib"
      ]
    }
  }
}

05 · The local corpus

The shelf ships empty. The books are yours.

Guides, manuals, maps, and saves are not distributed and never linked to. If you already own reference material, drop it into the corpus and the agent can query it directly instead of scraping the web.

  • Two layers. The public pack works with no corpus at all. The corpus is the second layer: your material, indexed locally.
  • Offline by design. Ingest and query never touch the network. The index is SQLite FTS5 and stays gitignored.
  • Text versus facts. Facts learned from a source may enter a pack with credit. The source text itself never does.
  • Japanese in, Japanese out. Text decodes through UTF-8, CP932, and EUC-JP, with a trigram index so a query like the one below still finds the page.
# create the folders for one game
python library/tools/scaffold_corpus.py \
  --platform snes --game secret-of-the-stars

# index what is there
python library/tools/ingest_corpus.py \
  --corpus library/corpus --game secret-of-the-stars

# ask it something
python library/tools/query_corpus.py "town data" \
  --game secret-of-the-stars
python library/tools/query_corpus.py "魔王" \
  --game secret-of-the-stars

The rules are short. Do not commit the corpus or its index. Do not add download links, scrapers, or mirrors of copyrighted material. A source that forbids redistribution stays local-only, recorded by title, author, and license in a manifest that is also gitignored.

06 · Authoring

An Academy, not a style guide.

A master skill walks an agent through building a pack: identify the edition, inventory the material, triage sources, read the game before the guides, verify in Mesen, write the pack, then review it against a 100-point rubric.

  • Seven lessons that end with a filled template, not a reading list.
  • A 100-point rubric over coverage, evidence, reproducibility, rights, and clarity. Certification needs 80 or more, no category below 60 percent, and zero rights failures.
  • Templates and checklists for intake, data verification, and review.
  • Two worked examples that pass the rubric, both shipped in the authoring bundle.

07 · Rights

What is deliberately missing.

The repository contains original prose, data compiled from observation and public references, and code. It does not contain, link to, or help you obtain the games or the guides about them.

Not included

ROMs, guide text, manual scans, map renders, savestates, patches, or ripped art. No download links, no mirrors, no scrapers.

Licensing

Pack prose, data compilations, schematics, and variants are CC BY-SA 4.0. Tools and Lua code are GPL-3.0. Source metadata keeps each source's own license.

Credit

Every public source is credited by title, author, and license in the pack's manifest. Local-only sources are credited the same way, without paths or links.

Takedown

If something should not be here, open an issue or follow the takedown policy. Content is removed first and discussed second.

Use only ROMs you are entitled to use. The emulator and the server ship no game data, and neither does the library.
