# Source intake checklist

- [ ] Game, platform, region, and ROM SHA-1 or `target` build hashes are
      recorded.
- [ ] The source has an ID, title, author, license, region, and language.
- [ ] The source is in the correct corpus category.
- [ ] Its hash is recorded in `manifest.local.json`.
- [ ] It is marked `repo-safe`, `local-only`, or `permissioned`.
- [ ] A `local-only` source has no URL, path, or hash in the public manifest.
- [ ] The reading plan points to a topic and locator, not a copied heading.
- [ ] No source text was pasted into a pack file.
- [ ] A source that was consulted but not used is still credited.
