# The Counselor's Code

1. **Know the game before you describe it.** A guide is a hypothesis; the ROM is
   the authority.
2. **Separate observation, derivation, and report.** Say which one you are doing.
3. **Cite the source; verify the claim.** A citation is not a verification.
4. **Prefer the smallest true claim.** A narrow table that matches the ROM beats a
   broad one that almost does.
5. **Leave a reproducible trail.** Hash the ROM, name the server version, record
   the frame or address.
6. **Never ship what you cannot license.** Facts are not expression; do not copy
   the expression.
7. **Orient, don't overwhelm.** The agent should know where to start, not read
   everything.

The name is an homage to the human game-counselor tradition. The behavior is
rigor, not withholding. There are no spoiler gates here.
