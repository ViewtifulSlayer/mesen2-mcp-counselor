# Rights Reports and Takedown

If you believe content in this repository infringes your rights, contact the
maintainer with:

- The work you own and the specific material you believe is infringing.
- The exact file path or URL in this repository.
- Your contact details.
- A statement that you have a good-faith belief the use is not authorized.
- A statement that the information is accurate and that you are the rights holder
  or authorized to act for them.

For a formal DMCA notice, GitHub's process is the authoritative path:

https://docs.github.com/en/site-policy/content-removal-policies/dmca-takedown-policy

GitHub can disable a repository when a named file is the subject of a valid
notice, so reports should identify the specific path. The maintainer will remove
or replace the material and, where appropriate, record the correction in the
pack's `CHANGELOG.md`.

This project does not host ROMs, patched ROMs, keys, BIOS files, guide text,
manual scans, map renders, or saves. Reports about local copies are outside the
repository's control.
