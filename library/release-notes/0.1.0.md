# Counselor Library 0.1.0

A game-context library for [Mesen2 MCP](https://github.com/Azarem/mesen2-mcp). The
emulator and MCP server are unchanged; this release adds `library/` on top of them,
so upstream can still be merged cleanly. A pack gives an agent enough grounded
context to play, test, reverse-engineer, patch, or localize one game without
burning thousands of frames on missing information. It is not a hint line: there
are no spoiler gates, only traceable claims.

This is a fork of Azarem's server and follows its `0.6.0` behavior. The library is
additive and can be copied into any existing `mesen2-mcp` checkout.

Both packs ship `SKILL.md`, seven reference pages, data tables with provenance,
schematics, Lua recipes, a field-test record, and a certification score against
the Academy rubric. Every substantive claim carries `[V]` (field-tested), `[D]`
(documented), or `[U]` (unverified).

Neither pack pretends to be complete. Final Fantasy Legend's region variants are
an outline; Secret of the Stars has no walked entrance to the Ancient Well and
says so rather than inventing one. Each pack's `CERTIFICATION.md` lists its
deductions.

## The Academy

`counselor-pack-author` is the authoring skill: it tells an agent where a pack's
information goes, what to verify in Mesen instead of trusting a guide, and how to
keep copyrighted text out of the public tree. It ships with seven lessons:

1. Identify the edition
2. Inventory the corpus
3. Triage sources
4. Read the game before the guides
5. Verify in Mesen
6. Write the pack
7. Review and certify

The rubric is 100 points across coverage (30), evidence (25), reproducibility
(20), rights and provenance (15), and orientation (10). Certification requires at
least 80 overall and no category below 60%. A pack template, checklists, and the
validator make the rubric enforceable rather than advisory.

## Corpus rules

The public repository contains no guides, manuals, maps, ROMs, saves, or patches.
It does not link to them or tell you where to download them.

Your own reference material goes in `library/corpus/<platform>/<game>/`, which is
empty in a fresh clone and gitignored: `guides/`, `manuals/`, `maps/`, `data/`,
`websites/`, `regional/`, `saves/`, `roms/`, `patches/`, `notes/`. Ingest builds a
local SQLite FTS index: UTF-8, then CP932/Shift_JIS, then EUC-JP, with a trigram
index for Japanese when SQLite supports it. Manuals, maps, saves, ROMs, and patches
are catalogued only (path, size, SHA-256, kind, language); their text and pixels
are never extracted into the library.

```bash
python library/tools/scaffold_corpus.py --platform snes --game secret-of-the-stars
python library/tools/ingest_corpus.py --corpus library/corpus --game secret-of-the-stars
python library/tools/query_corpus.py "town data" --game secret-of-the-stars
```

Two manifests keep the line visible. `sources/manifest.public.json` carries title,
author, license, and what was used; `sources/manifest.local.json` carries paths,
URLs, hashes, and page lists for material that cannot be redistributed, and is
gitignored. Facts may enter a pack. Text may not. A pack stays usable with no
corpus at all.

## Tools and CI

`library/tools/` ships the scaffold, ingest, query, validate, catalog, bundle,
install, record-source, and source-check scripts. `library.yml` validates every
library change: schema validation for all packs and the template, catalog and page
index freshness, the tool test suite, and a bundle inspection. Pushing a
`library-v*` tag that matches `library/VERSION` publishes the bundles.

Pack archives extract straight into `.agents/skills/<skill-name>/`. Every archive
adds `BUNDLE_INFO.txt` and `INSTALL.md`; every release adds `SHA256SUMS.txt`.
Bundles are built from git-known files only, so the corpus and local manifests
cannot enter them, and the test suite is not shipped.

## Install

```bash
python library/tools/install_pack.py --pack gb/final-fantasy-legend --target .agents/skills
```

The installer prints the `--mcp-lib-dir` value for the pack's Lua kit; add it to
the Mesen2 MCP server arguments and restart the client so the skill list reloads.
The tools need Python 3 and `library/tools/requirements.txt`; the server needs
.NET 8 and Mesen2 MCP 0.6.0.
